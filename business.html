    Production grade

    What “production grade”
    means in my work

    These ship in every build. Each one is already running in a system I built.

    Auth & permissions
    JWT auth, multiple roles per user, read and write access set per module.
    Audit trail
    Every change records who made it and when, so mistakes can be traced and undone.
    Background jobs
    Email, payment webhooks and PDFs run in workers (Redis, arq), so requests stay fast.
    Fast dashboards
    Heavy reports read from summary tables filled overnight, not from live queries on every page load.
    Safe deploys
    CI/CD with health checks. No stored cloud keys and no open SSH port on the servers.
    Safe migrations
    Run on a pilot first, with uploaded files checked against checksums before go-live.
    AI that's checked
    Model output is validated before use. If the answer doesn't fit real data, users see “no match” instead of a wrong answer.
    Known AI costs
    Cost tracked per feature and per model, and checked against the provider's own billing.

      FAQ

      Before you ask

      Can a real product be built in 7 days?

      A focused first release, yes: the core flow, auth, database and a production deploy. Larger products ship as a series of 7-day releases, and each one is live and usable, not a mockup.

      Who owns the code?

      You do. The repo, cloud accounts and domains are in your name from day one, and you get documentation at handover.

      Do you work with an existing codebase?

      Yes. I can join your repo, follow your conventions and ship features, fix bugs or finish a stalled project.

      What stack do you use?

      The FARM stack (FastAPI, React, MongoDB), or PostgreSQL when the data is relational, deployed with Docker on AWS or a VPS. If your team already uses something else, I'll work in that.

      Do you build mobile apps?

      I build web apps, including installable ones (PWAs) that sit on the home screen like an app. For most products that means one codebase, no app-store wait, and updates that reach every user instantly. If you need a native app later, the same backend serves it.

      Will you sign an NDA?

      Yes, before you share anything sensitive.

      What happens after launch?

      You get a free bug-fix window after each release. After that I can maintain and extend it on a monthly retainer, or hand it over fully to your team.
